# Windows 11 shell: local proof of concept

A browser replica of the Windows 11 desktop for Mihawk OS, to judge the look and behaviour
before the native Wine shell copies it. It runs locally; nothing is sent anywhere.

## Run it

```sh
prototypes/windows11-shell/serve.sh
```

Then open <http://127.0.0.1:8765/prototypes/windows11-shell/> in Chromium or Chrome, and press
F11 for full screen (hold Esc to leave). In full screen the page asks the browser for the Win key
and Alt+Tab (Keyboard Lock); outside it your desktop keeps them, so every `Win+<key>` also works as
`Ctrl+Alt+<key>`, and Alt+\` stands in for Alt+Tab.

`serve.sh` draws the desktop's wallpaper, the project's own Aero Meadow, and its night variant
into `local/` with `tools/make-mihawk-wallpaper.py` (about a minute, again only when the
generator changes). Until they load the desktop shows a gradient.

Settings, icon positions and files are remembered in the browser. `?fresh` starts from the
defaults without saving anything; Settings has no reset, so clear it with
`Shell.resetAll()` in the browser console.

## What to try

| Area | Try |
| --- | --- |
| Desktop | Drag icons to new cells, drag a selection rectangle, right-click empty space and icons, F2 to rename, drag a file onto Recycle Bin or into an Explorer window |
| Taskbar | Hover and click apps, hover a running app for its thumbnail, right-click an app, the tray, the clock, the far-right corner, right-click Start (Win+X) |
| Start and Search | Start button or Win key, type to search, All apps, the power button |
| Windows | Drag title bars to edges and corners, hover Maximize for Snap Layouts, Win+arrows, double-click a title bar, resize from any edge |
| Flyouts | Quick Settings (Win+A), notifications and calendar (Win+N), Task View (Win+Tab), Alt+Tab, Win+V and Win+. |
| Apps | File Explorer (Win+E), Settings (Win+I; Personalization changes the whole shell live), Notepad, Calculator, Terminal, Task Manager (Ctrl+Shift+Esc), Run (Win+R), Windows controls (All apps) |
| Session | Win+L to lock, Start > power > Restart or Shut down, Alt+F4 on the desktop |
| Not responding | In Terminal, type `hang 10`, then click the window or end it in Task Manager |

## What it is and is not

- Every colour, radius, size and timing comes from `docs/windows11-reference/` and
  `themes/windows11/appearance.json` through `css/tokens.css` (generated by
  `tools/gen-tokens.py`). The font is Proton UI (Selawik, OFL), or Segoe UI Variable when your
  PC has it. Icons are the repository's approved originals plus MIT Fluent System Icons at the
  pinned revision (`assets/icons/`); cursors are original artwork (`assets/cursors/`). Terminal and
  Notepad use Cascadia Mono (OFL, `assets/fonts/cascadia/`) and the emoji panel draws Fluent Emoji
  (MIT, `assets/emoji/`), each pinned with its licence and hashes.
- File names, sizes, notifications, networks and Task Manager figures are made-up demo data.
- Checked in headless Chromium at sizes from 390×844 to 2560×1440, light and dark. Firefox
  and Safari were not tested.
- It proves nothing about the PS5. The native shell's cost in memory and compositor time is
  measured on the console when each surface is ported (`docs/WINDOWS11_PLAN.md`).
